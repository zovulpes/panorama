# Работа студии панорамной видеосъёмки

Учебная практика Матяшовой Зои Александровны ИКБО-31-24

## Тема

Работа студии панорамной видеосъёмки.

## Объект исследования

Деятельность студии панорамной видеосъёмки.

## Предмет исследования

Бизнес-процесс обработки заказа на панорамную видеосъёмку от поступления заявки клиента до передачи готового видеоматериала.

## Цель проекта

Разработка программного решения для автоматизации бизнес-процесса обработки заказа на панорамную видеосъёмку.

## Основной бизнес-процесс

В рамках проекта рассматривается процесс обработки заказа на панорамную видеосъёмку, включающий:

1. Получение заявки клиента.
2. Уточнение требований к съёмке.
3. Оценку стоимости и сроков выполнения заказа.
4. Согласование условий с клиентом.
5. Планирование съёмки и назначение исполнителей.
6. Подбор необходимого оборудования.
7. Проведение панорамной видеосъёмки.
8. Обработку полученного видеоматериала.
9. Контроль готового результата.
10. Передачу готового панорамного видеоматериала клиенту.

Основное направление автоматизации связано с сопровождением заказа: хранением данных о клиентах и заказах, контролем статусов, учётом сотрудников и оборудования, а также планированием сроков выполнения работ.

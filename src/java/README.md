# ООП-версия программы студии панорамной видеосъёмки (КТ3)

Язык: Java 21 (JDK 21). Сборка: `javac`, дополнительные библиотеки не нужны.
Программа запускается в консоли, база данных и графический интерфейс не используются.

## Сборка и запуск

1. Откройте PowerShell или терминал в `src/java`.
2. Выполните команды:

```powershell
javac -encoding UTF-8 panorama/kt3/Main.java
java panorama.kt3.Main
```

Исходники расположены в пакете `panorama.kt3`; он отделён от процедурного `src/Main.java` КТ2.

Программа создаёт примеры клиентов, заказов, сотрудников и оборудования, проверяет
пересечение расписания, рассчитывает стоимость и срок, бронирует ресурсы и завершает заказ.

## Пример данных и результата

Заказ: панорамное видео 4K продолжительностью 10 минут. Первое окно съёмки:
05.11.2026 10:00–14:00; альтернативное: 15:00–19:00.
Тариф обработки — 250 руб./мин, работа специалистов — 4 ч × 1200 руб./ч и
3 ч × 900 руб./ч, оборудование — 4 ч × 500 руб./ч и 4 ч × 150 руб./ч.

Ожидаемые строки вывода:

```text
Заказ №2 зарегистрирован. Статус: новый
05.11 10:00–14:00: ресурсы доступны? нет
05.11 15:00–19:00: ресурсы доступны? да
Предварительная стоимость: 12600.00 руб.
Ориентировочный срок: 05.11.2026 21:20
После резервирования статус: запланирован
Итоговый статус: завершён
Назначений сотрудников: 3; резервирований оборудования: 3
Видеоматериалов по заказу: 2
```

Сценарий и вывод совпадают с процедурной программой КТ2 (`src/Main.java` в
репозитории) при тех же исходных данных. Чтобы сравнить две версии,
запустите обе отдельно и сопоставьте консольные результаты.

## Структура

Классы `Client`, `Order`, `Employee`, `Equipment`, `EmployeeAssignment`,
`EquipmentReservation`, `OrderStage`, `VideoMaterial` отражают восемь сущностей
логической ER-модели КТ2. `StudioService` выполняет операции с заказами.
`CameraOperator` и `VideoEditor` наследуют `Employee`.
`ProcessingRule` реализован классами `FourKProcessingRule` и
`HighResolutionProcessingRule`. Объекты хранятся в `List` и `Map`.

Специальных тестовых библиотек нет. Для проверки предусмотрен запуск
демонстрационного сценария командой `java panorama.kt3.Main`.

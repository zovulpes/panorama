# КТ2 — студия панорамной видеосъёмки

## Что делает программа

Программа регистрирует заказы, проверяет доступность сотрудников и оборудования, рассчитывает стоимость и срок выполнения заказа, назначает ресурсы и обновляет статус заказа.

Написана на **Java 21** в процедурном стиле. Для хранения данных используются списки и словари Java. Дополнительные библиотеки и база данных не требуются.

## Как собрать и запустить

Нужен установленный JDK 21.

Откройте терминал в папке `src` и выполните:

```bash
javac -encoding UTF-8 Main.java
java Main
```

## Пример работы

Программа создаёт пример заказа и проверяет два времени съёмки. Если ресурсы заняты, выбирается свободный интервал. Затем рассчитываются стоимость и ориентировочный срок.

Пример вывода:

```text
Заказ №2 зарегистрирован. Статус: новый
05.11 10:00–14:00: ресурсы доступны? нет
05.11 15:00–19:00: ресурсы доступны? да
Предварительная стоимость: 12600.00 руб.
Ориентировочный срок: 05.11.2026 21:20
После резервирования статус: запланирован
Итоговый статус: завершён
```

Данные демонстрационные и хранятся только в оперативной памяти. После завершения программы они не сохраняются.
